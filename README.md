Tamil Handwritten OCR System

Project Overview

This project performs Tamil handwritten character recognition using deep learning techniques.

The system uses ResNeXt architecture for feature extraction and Transformer-based learning for recognizing Tamil handwritten characters.

The model processes handwritten images and predicts Tamil characters with confidence scores.
